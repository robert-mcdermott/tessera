Configuration

Tessera reads one file, tessera.toml. uv run tessera init writes a commented starting point; the same file is in the repository as tessera.example.toml. Every setting has a sensible default except the organization profile.

Tessera checks the whole file when it starts and reports every problem at once, with the setting's name, so a typo never fails silently. Unknown sections and settings are errors too.

Where the file is#

Commands look for the configuration in this order:

  1. --config PATH (or -c PATH) on the command line;
  2. the TESSERA_CONFIG environment variable;
  3. tessera.toml in the current folder.

Relative paths inside the file (the data home, logo files) are relative to the file's own folder.

Environment variables#

A simple setting can be overridden by an environment variable named TESSERA_<SECTION>_<SETTING>, which is handy for containers and services:

TESSERA_SERVER_PORT=9000 uv run tessera serve
TESSERA_DATA_HOME=/srv/tessera/data uv run tessera sync
TESSERA_LEDGER_URL="postgresql+psycopg://tessera@db/tessera" uv run tessera serve

Secrets never go in the file. The only secret Tessera uses, an optional NCBI API key, is read from the environment variable named by [sources.pubmed] api_key_env.

[organization]#

How the organization appears in public records. See Describing your organization for how to choose values.

SettingTypeDefaultMeaning
nametext(required)Full name, shown in the app and used as an alias
short_nametext""Short form for the sidebar
aliaseslist[]Names as written in affiliations, sponsor and site names
affiliation_patternslist[]Affiliation patterns; * matches any run of characters in a word
reporter_org_nameslist[]Organization names exactly as NIH RePORTER writes them
ctgov_org_nameslist[]Sponsor, collaborator, and site names in ClinicalTrials.gov (falls back to aliases)
email_domainslist[]Domains whose addresses count as evidence of membership
exclusionslist[]Look-alike organizations that contain one of the aliases

name and at least one of aliases, affiliation_patterns, or reporter_org_names are required, so Tessera can recognize the organization.

[branding]#

SettingTypeDefaultMeaning
product_nametext"Tessera"The product's name in the sidebar and page titles
themetext"tessera"The default color palette: tessera, harbor, or cassette
accent_colorcolor(none)Replaces the palette's accent: a hex value, a color name, or rgb(), hsl(), or oklch()
logo_lightpath(none)Your logo, shown in the sidebar in place of the Tessera mark and name (SVG, PNG, JPEG, or WebP)
logo_darkpath(none)The logo for dark mode; the light one is used if absent
show_powered_bytrue/falsetrueThe small "Powered by Tessera" line in the sidebar

Palettes. Each palette has a light and a dark version, and every viewer can switch palettes and modes for themselves under Appearance in the top bar; theme sets what everyone sees first.

PaletteBy dayAfter dark
tesseraCalm cool neutrals with an indigo accentNeutral graphite with a soft indigo accent
harborWhite and light grey, dark navy text, teal actions, a navy-to-gold ruleDeep navy, bright blue actions, gold and purple accents
cassetteCream label paper, a red-orange accent, a thin sunset stripeBlack labels, an orange accent, the same sunset stripe

A configured accent_color is used as given by day and lightened for dark mode. It also colors links and labels, so choose one that reads on white at a contrast of at least 4.5:1, such as a deep blue or teal rather than a yellow. Write it as a hex value so that text on accent-colored buttons can be chosen for contrast; with other forms that text is white. Tessera and Harbor suit public and leadership views best; Cassette is playful by design. Logos look best at about 190 by 30 pixels.

SettingTypeDefaultMeaning
homepath"var"The data home: raw downloads, the Parquet lake, the ledger (with SQLite), the search index, and logs. See Running Tessera

SettingTypeDefaultMeaning
hosttext"127.0.0.1"Address to listen on. Anything other than this machine needs accounts = true
portnumber8000Port to listen on
operatortext"Operator"Without accounts, the name recorded on every curation decision
accountstrue/falsefalseRequire sign-in with local accounts and roles; see Accounts and sign-in
session_idle_hoursnumber12A session ends this long after it was last used (1 to 720)
session_max_daysnumber7A session never lasts longer than this from sign-in (1 to 90)

[ledger]#

The ledger holds people, links, and decisions.

SettingTypeDefaultMeaning
urltext""Empty means SQLite at <data home>/ledger.db. For PostgreSQL: postgresql+psycopg://user@host/dbname

PostgreSQL support needs the postgres extra: uv sync --extra postgres. See Running Tessera.

[sources]#

SettingTypeDefaultMeaning
contact_emailtext""Sent with requests to the public APIs, as their usage policies ask. Set it to an address that can be reached

Each source has its own table, [sources.pubmed], [sources.icite], [sources.reporter], [sources.ctgov], and [sources.orcid]:

SettingTypeDefaultMeaning
enabledtrue/falsetrueWhether sync and ingest all use the source
api_key_envtext"NCBI_API_KEY" for PubMed, else ""The environment variable holding an optional API key

An NCBI API key (created under API Key Management in your NCBI account settings) raises PubMed's request limit from three to ten per second, which shortens the first sync of a large organization considerably.

[sync]#

SettingTypeDefaultMeaning
window_yearsnumber5How many years of history the first sync collects. Later syncs fetch only what changed

[evidence]#

Thresholds for authorship suggestions. See Curating.

SettingTypeDefaultMeaning
strong_threshold0 to 10.95Suggestions at or above this likelihood are strong
review_threshold0 to 10.60Suggestions below this are unlikely and hidden by default
store_threshold0 to 10.05Candidates below this are not recorded at all
discover_min_papersnumber2Affiliated papers needed before a person is proposed under Discovered people, or a grant co-investigator is promoted

Changing a threshold takes effect at the next tessera resolve or sync; decisions already made are not affected.

[discovery]#

Concept profiles and similar people. See Finding experts.

SettingTypeDefaultMeaning
half_life_years0.5 to 505.0A paper's weight in a profile halves every this many years
likely_weight0 to 10.5How much a strong suggestion not yet confirmed counts, relative to a confirmed paper. 0 builds profiles from confirmed papers only
similarity_floor0 to below 10.10Pairs of people less similar than this are not listed as similar
similar_per_person1 to 20025At most this many similar people are kept for each person

Changes take effect at the next tessera sync or tessera build discovery.
