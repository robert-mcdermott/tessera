API reference

Every response is {"data": …, "meta": …}. Lists take limit and an opaque cursor (use meta.next_cursor); fields=a,b trims list items. Errors are RFC 9457 problem details (application/problem+json). Search highlights wrap matches in U+E000 and U+E001; escape the text, then replace them.
