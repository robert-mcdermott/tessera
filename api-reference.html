API reference

Every endpoint of the JSON API, generated from Tessera's OpenAPI document (version 0.2.0). For conventions, sign-in, and examples, see The API. A running instance serves the same reference at /api/docs and the document itself at /api/openapi.json.

System#

GET /api/v1/health#

Liveness and readiness

``200`` when the ledger and lake are usable, ``503`` otherwise, with per-check detail.

GET /api/v1/meta#

Product, branding, and organization details for the web app

POST /api/v1/people/{person_id}/identifiers#

Add, confirm, reject, or remove one of a person's identifiers (logged)

Confirming an ORCID iD makes it decisive evidence from the next resolve or sync, and its public record is read at the next sync. A rejected iD is kept so that it is never proposed again and counts against papers that carry it.

ParameterInTypeRequiredMeaning
person_idpathstringyes

JSON body:

FieldTypeRequiredMeaning
schemestringorcid, email, nih_profile, or local
valuestringyes
actionstringyesadd, accept, reject, or remove
notestring

POST /api/v1/merges#
